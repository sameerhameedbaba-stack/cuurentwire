## Owner checklist — switch-over (about 10 minutes of clicks)

Do these in order. Step 1 must come before step 2.

1. **Turn on Pages.** GitHub → `cuurentwire` repo → Settings → Pages →
   *Build and deployment* → Source: **GitHub Actions**.
2. **Merge** branch `claude/brave-brahmagupta-9dcghr` into `main` (or tell
   Claude "merge it"). The *Deploy site (GitHub Pages)* workflow runs, ~4 min.
   Wait for it to go green.
3. **Custom domain.** Settings → Pages → Custom domain: `currentwire.us` →
   Save. A failed/pending DNS check here is expected until step 4.
4. **DNS at Hostinger** (Domains → currentwire.us → DNS records):
   - **Delete** the A record `@` → `216.198.79.1` (Vercel).
   - **Add** four A records for `@`: `185.199.108.153`, `185.199.109.153`,
     `185.199.110.153`, `185.199.111.153`.
   - *(Recommended)* **Add** four AAAA records for `@`:
     `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`,
     `2606:50c0:8003::153`.
   - **Change** the CNAME `www` → `sameerhameedbaba-stack.github.io`
   - **Do not touch** MX, the SPF TXT, the `google-site-verification` TXT,
     DKIM or DMARC. Email and Search Console depend on them.
   (Addresses verified today from GitHub's own DNS.)
5. **HTTPS.** Wait 10–60 minutes (old records have a 4-hour TTL, so some
   networks may take a few hours). When Settings → Pages shows the DNS check
   passed, tick **Enforce HTTPS**. Until the certificate is issued, some
   browsers may show a certificate warning — expected, and it clears itself.
6. **Search Console → Sitemaps:** remove `news-sitemap.xml` and
   `archive-sitemap.xml` (retired); resubmit `sitemap.xml`. Optional: URL
   Inspection → *Request indexing* on the two article URLs.

Optional hardening: GitHub → your account Settings → Pages → *Add a verified
domain* → `currentwire.us` (adds one TXT record; stops anyone else claiming
the domain on GitHub Pages).

Nothing to do on Vercel: its git deployments are switched off from the repo
(`vercel.json`), and nothing there can bill.
